# Convite de Aniversário

Página-convite digital desenvolvida para divulgar um evento de aniversário de forma visual, simples e interativa.

Projeto de Front-End criado para praticar a construção de uma página temática para eventos.

## Demonstração

Acesse a versão online do projeto:

[Visualizar convite online](https://aniversario-evento-ten.vercel.app/)

## Sobre o projeto

A página foi criada como um convite digital para uma comemoração de aniversário. A proposta é apresentar as principais informações do evento em uma interface temática, com destaque para a data, o local e o horário da celebração.

O projeto também conta com uma contagem regressiva para o evento e um botão interativo de confirmação.

## Informações do evento

- Data: 01 de julho
- Horário: 19h
- Local: Amparo - SP

## Funcionalidades

- Apresentação visual do convite;
- Exibição das informações principais do evento;
- Contagem regressiva em dias, horas, minutos e segundos;
- Botão interativo para confirmar a presença;
- Layout adaptável para diferentes tamanhos de tela;
- Interface com identidade visual temática;
- Efeitos visuais, gradientes e animações em elementos da página.

## Como executar o projeto localmente

### Pré-requisitos

Antes de começar, você precisa ter instalado:

- [Node.js](https://nodejs.org/)
- NPM, que normalmente é instalado junto com o Node.js

### Instalação

Clone este repositório:

```bash
git clone https://github.com/Marcela-prog/aniversario-evento.git
```

Entre na pasta do projeto:

```bash
cd aniversario-evento
```

Instale as dependências:

```bash
npm install
```

### Desenvolvimento

Inicie o servidor de desenvolvimento com o Parcel:

```bash
npm run dev
```

O terminal exibirá o endereço local para acessar a página no navegador.

### Build de produção

Para gerar uma versão otimizada do projeto:

```bash
npm run build
```

Os arquivos compilados serão gerados na pasta dist.
